## Кто мы

**CoreX Systems / ООО «Корекс Системы»** — инженерная компания, которая проектирует системы искусственного интеллекта, данных и автоматизации с опорой на архитектуру, измеримые критерии и воспроизводимые эксперименты.

Мы начинаем с задачи и ограничений, а не с выбора модели или технологического стека. Для каждого решения важны проверяемость результата, безопасность, стоимость владения и готовность к промышленной эксплуатации.

## Наш подход

**Задача → архитектура → базовый уровень → эксперимент → оценка → промышленный запуск.**

- **Архитектура первична:** определяем границы решения, риски и требования до выбора инструментов.
- **Метрики важнее демонстраций:** сравниваем результаты с заранее заданным базовым уровнем.
- **Простое решение предпочтительнее сложного:** не используем ИИ там, где достаточно надежной детерминированной автоматизации.
- **Контроль и воспроизводимость:** учитываем права доступа, доказательную базу, стоимость, мониторинг и возможность отката.
